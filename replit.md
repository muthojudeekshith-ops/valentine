# Heart Animation

## Overview
A Valentine's Day heart animation web page with multiple screens:
1. A "NEXT" button screen
2. A password entry screen (password: "SHAWARMA")
3. A typing animation screen displaying a love message

## Project Structure
- `root/` - Static website files
  - `index.html` - Main HTML page
  - `style.css` - Styles
  - `script.js` - Screen logic, typing effect, and heart canvas animation

## How to Run
The project is served as a static site using `serve` on port 5000.

## Deployment
Configured as a static deployment serving the `root/` directory.
